# Установка .ipa на iPhone через SideStore (с Windows-ПК)

Документ описывает полный путь: от коммита в GitHub до работающего приложения
на iPhone. Компьютер с macOS не нужен ни на одном шаге.

- Сборка `.ipa` происходит в GitHub Actions на macOS-раннере (см. `.github/workflows/build-ios.yml`).
- `.ipa` **не подписан**. Подпись выполняется на самом iPhone приложением SideStore
  вашим Apple ID.
- Первоначальная установка SideStore требует один раз подключить iPhone к Windows-ПК кабелем.

---

## 1. Требования

| Что | Детали |
|---|---|
| iPhone | iOS/iPadOS **15.0 или выше**, обязательно **включён код-пароль** |
| Apple ID | Бесплатного достаточно. Подойдёт любой Apple ID (не обязательно тот, что на устройстве) |
| Wi-Fi | Обязателен на iPhone. Мобильный интернет не подходит для работы SideStore |
| ПК | Windows 8 или выше — нужен только для первичной установки SideStore |
| GitHub | Репозиторий с workflow; для скачивания `.ipa` нужен публичный доступ к Releases |

Важные предупреждения:

- Используйте для sideloading **отдельный Apple ID**, а не основной. Бесплатные аккаунты
  изредка блокируются при аномальной активности, и восстанавливать основной аккаунт больно.
- Всё, что связано с подписью, живёт 7 дней (у бесплатного аккаунта). Приложения нужно
  периодически «обновлять» (refresh) через SideStore.
- Flutter-сборка в режиме **release** использует AOT-компиляцию, поэтому **JIT не нужен** —
  инструкции про StikDebug/JIT можно игнорировать.

## 2. Получаем .ipa из GitHub Actions

1. Откройте репозиторий → вкладка **Actions** → workflow **Build unsigned iOS IPA**.
2. Нажмите **Run workflow** → выберите ветку `main`.
   - `flutter_version` — оставьте `3.41.6`.
   - `make_release` — `true`, чтобы сборка сразу попала в Releases.
3. Дождитесь зелёной галочки (первая сборка ~5–10 минут: скачивание Flutter SDK,
   `pub get`, сборка Xcode; последующие быстрее за счёт кэша).
4. Забрать результат можно двумя способами:
   - **Releases** (удобно для iPhone): раздел **Releases** → тег вида `ios-build-12` →
     файл `flutter_test_app-0.1.0+1-unsigned.ipa`. Ссылку можно открыть прямо в Safari на iPhone.
   - **Artifacts**: внизу страницы запуска workflow → `flutter-test-app-unsigned-ipa`.
     Для скачивания нужна авторизация в GitHub, поэтому на телефоне это менее удобно.

Дальше: скачайте `.ipa` на iPhone. Откройте ссылку Releases в **Safari** на телефоне →
нажмите на файл → «Загрузить». Файл попадёт в приложение **Файлы** → «Загрузки» (iCloud Drive
или «На iPhone»). Именно оттуда его заберёт SideStore.

---

## 3. Установка SideStore через iloader

> Установщик называется **iloader** (раньше — iLoader). Официальные источники — только
> [iloader.app](https://iloader.app) и [репозиторий на GitHub](https://github.com/nab138/iloader).
> Проблемы с самим iloader разбирают в [idevice Discord](https://discord.gg/mACqxMxP3X),
> а не в поддержке SideStore.

### 3.1. На Windows: драйверы и iloader

1. Установите **iTunes** с сайта Apple ([apple.co/ms](https://apple.co/ms)) — он даёт
   драйвер `usbmuxd`, без которого iloader не увидит iPhone. Версия из Microsoft Store
   тоже обычно подходит, но классический iTunes надёжнее.
2. Скачайте установщик iloader для Windows со страницы
   [releases](https://github.com/nab138/iloader/releases/latest) или с [iloader.app](https://iloader.app).
3. Установите и запустите iloader.

### 3.2. На iPhone: LocalDevVPN

4. Установите **LocalDevVPN** из App Store:
   [LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044).
   Это официальный VPN-компонент SideStore (раньше он был встроен в само приложение).
   - Если приложение недоступно в вашем регионе App Store — понадобится Apple ID
     другой страны. Это единственный шаг, который может потребовать смены региона.
5. Откройте LocalDevVPN → **Connect**. При запросе «Allow VPN Configurations» нажмите
   **Allow** и введите код-пароль.

> VPN обязательно должен быть включён каждый раз, когда вы устанавливаете, обновляете
> или продлеваете приложения в SideStore. Трафик он не гонит: подключение локальное,
> к самому устройству.

### 3.3. Ставим SideStore с ПК

6. Подключите iPhone к компьютеру **кабелем**. На телефоне нажмите **Доверять** и введите код-пароль.
7. В iloader нажмите войти и введите свой **Apple ID** (регистр символов важен!).
8. Выберите своё устройство в списке.
9. Нажмите **Install SideStore (Stable)** и дождитесь завершения.

---

## 4. Первичная настройка iPhone

Порядок важен — не пропускайте шаги.

10. **Доверие сертификату**: Настройки → **Основные** → **VPN и управление устройством** →
    в разделе «Приложение разработчика» выберите запись со своим Apple ID → **Доверие …** →
    **Разрешить и перезапустить** → введите код-пароль.
11. **Режим разработчика**: Настройки → **Конфиденциальность и безопасность** → прокрутите
    вниз → **Режим разработчика** → включите → устройство перезагрузится → после перезагрузки
    подтвердите включение.
    (На iOS 16+ этот пункт появляется только после того, как на устройстве появилось
    приложение, подписанное сертификатом разработчика, — то есть после шага 10.)
12. Убедитесь, что **LocalDevVPN подключён** и **Wi-Fi включён**.
13. Откройте **SideStore** → войдите тем же Apple ID, который использовали в iloader.
14. Перейдите в **My Apps** → нажмите на счётчик **«7 DAYS»** справа от SideStore, чтобы
    вручную продлить его. Это финальный шаг установки.
    - Если появится запрос про отзыв или создание нового сертификата подписи — нажмите
      **Yes** / **Refresh Now**.
15. Если всё прошло успешно, SideStore закроется, вернётся на домашний экран и снова
    появится через несколько секунд (придёт уведомление).

Дополнительно стоит включить для SideStore фоновое обновление, чтобы он продлевал
приложения сам: Настройки → Основные → **Обновление контента** → включить для SideStore.

---

## 5. Устанавливаем наше .ipa

16. Скачайте `.ipa` на iPhone (см. раздел 2) — файл лежит в **Файлы** → «Загрузки».
17. Проверьте, что **LocalDevVPN подключён** и Wi-Fi активен.
18. Откройте **SideStore** → **My Apps** → нажмите **«+»** в левом верхнем углу.
19. Выберите скачанный `flutter_test_app-…-unsigned.ipa`.
20. Дождитесь установки. Если появится запрос о доверии сертификату — повторите шаг 10.
21. Запустите приложение с домашнего экрана.

Альтернативный путь (и он предпочтительнее для сборки с виджетом): подключите iPhone
кабелем, откройте **iloader** → **Import IPA** → выберите скачанный `.ipa`. iloader
подписывает вложенные расширения и аккуратно переносит entitlements, поэтому App Group
для виджета имеет больше шансов заработать, чем при установке через SideStore.

Проверка, что всё сработало: приложение запускается, добавление задачи работает.
Если приложение сразу закрывается при запуске — почти всегда причина в недоверенном
сертификате (шаг 10) или в выключенном режиме разработчика (шаг 11).

## 6. Виджет на главный экран

В `.ipa` встроено расширение `TodoWidget` — виджет с кратким списком задач.

Как добавить: длинное нажатие на пустом месте рабочего стола → **«+»** → найдите
**«Список дел»** → выберите размер (маленький / средний / большой) → «Добавить виджет».

### Как передаются данные и почему не через App Group

Обычный способ обмена между приложением и виджетом — общий контейнер App Group. На
бесплатном Apple ID он **недоступен**: iOS создаёт контейнер только если entitlement есть
в provisioning profile, а Apple добавляет App Groups лишь в платную программу Apple
Developer ($99/год). Это проверено на двух установщиках — SideStore и iloader: оба дали
«App Group не активирована» (SideStore при этом отвечает ошибкой `3014`).

Поэтому канал обмена — сеть, а именно приватный GitHub Gist:

```
Flutter  →  PATCH api.github.com/gists/<id>  →  Gist (todos.json)  →  URLSession в виджете
            токен со scope «gist»                  raw-URL              + кеш на случай офлайна
```

Перерисовка виджета (`reloadTimelines`) работает без App Group, поэтому после каждого
изменения задач виджет обновляется сразу.

### Настройка (один раз)

1. На github.com создайте **секретный** gist: файл `todos.json`, содержимое `[]`.
2. Скопируйте ссылку **Raw** на этот файл.
3. Создайте GitHub-токен: Settings → Developer settings → **Personal access tokens (classic)**
   → scope **`gist`**. Отдельный токен, не основной.
4. В приложении: иконка **шестерёнки** в правом верхнем углу → вставьте raw-URL и токен →
   **«Проверить связь»** (проверяет и чтение, и запись) → **«Сохранить»**.
5. В репозитории: Settings → Secrets and variables → Actions → добавьте секрет
   **`TODO_GIST_URL`** с тем же raw-URL.
6. Запустите сборку заново (Actions → **Build unsigned iOS IPA** → Run workflow) и
   переустановите `.ipa`: адрес виджету задаётся при сборке, потому что читать настройки
   приложения он не может.

### Что показывает приложение

Под счётчиком задач появляется строка статуса:

| Строка | Значение |
|---|---|
| «Виджет обновлён» | Задачи отправлены в Gist, виджет попросили перерисоваться |
| «Виджет не настроен: укажите Gist URL и токен» | Не заполнены настройки (иконка шестерёнки) |
| «Виджет: не удалось отправить данные — <причина>» | Ошибка с пояснением: 401 — токен, 404 — URL и т. д. |

Сам виджет без данных пишет «Задач пока нет» (всё работает, список пуст),
«Виджет не настроен» (при сборке не задан `TODO_GIST_URL`) или «Нет данных»
(нет сети и нет кеша).

### Ограничения сетевого варианта

- список задач хранится на сервере GitHub;
- токен лежит на устройстве в открытом виде — используйте отдельный токен только с `gist`;
- без интернета виджет показывает последние закешированные данные;
- если позже оформите платный Apple Developer, можно вернуться на App Group: файлы
  entitlements и подпись с ними в CI уже готовы.

### Влияние на лимиты бесплатного аккаунта

Расширение виджета — отдельный App ID (`com.example.flutterTestApp.TodoWidget`), поэтому
оно расходует лимит **10 App ID в неделю**, а также занимает место среди **3 приложений**
(считается вместе с основным приложением).

## 7. Лимиты бесплатного Apple ID

| Лимит | Значение |
|---|---|
| Одновременно установленных приложений | **3**, включая сам SideStore (то есть 2 ваших приложения) |
| Уникальных App ID за неделю | **10** |
| Срок жизни подписи | **7 дней**, после чего приложение не запустится до переподписи |

Как продлевать: держите LocalDevVPN включённым — SideStore продлевает приложения в фоне.
Если срок всё же истёк, откройте SideStore → My Apps → нажмите на счётчик дней у нужного
приложения. Данные приложения при продлении сохраняются.

Платный Apple Developer Program ($99/год) снимает ограничение в 3 приложения и даёт
подпись на 365 дней. Для наших задач бесплатного аккаунта достаточно, и он не нужен
для самой сборки в CI: сборка `.ipa` не подписывается и в Apple Developer не обращается.

## 8. Типичные проблемы

### SideStore: «AFC Connection Failure» / «You do not appear to be connected to Wi-Fi and/or LocalDevVPN»

Причина — нет связи с локальным сервисом `minimuxer`. По порядку:

1. Если используете WireGuard или StosVPN — переключитесь на **LocalDevVPN**.
2. Отключите DNS-блокировщики и «защиту от трекинга», если они включены.
3. Убедитесь, что LocalDevVPN **и** Wi-Fi подключены одновременно.
4. Попробуйте нажать кнопку ещё раз несколько раз (да, это официальная рекомендация).
5. Перезапустите SideStore → затем LocalDevVPN.
6. Пересоздайте pairing-файл через iloader (SideStore → Settings → pairing file).

### SideStore зависает в середине установки

1. Обновите SideStore или просто перезапустите его.
2. On-device: **Clear Cache**.
3. Смените **Anisette Server** (SideStore → Settings → Anisette URL).
4. В настройках серверов сбросьте `adi.pb`, выйдите из SideStore и войдите снова.
5. Перезагрузите устройство → при необходимости пересоздайте pairing-файл и переустановите
   SideStore через iloader.

### Приложение не запускается / вылетает сразу

1. Проверьте доверие сертификату (шаг 10) и включённый режим разработчика (шаг 11).
2. Проверьте, что LocalDevVPN подключён, и продлите приложение в My Apps.
3. Переустановите `.ipa` заново из свежей сборки.

### Ошибка входа в SideStore

Чаще всего это временная недоступность Anisette-сервера. Смените Anisette URL в настройках
SideStore. Не используйте случайные публичные серверы — они приводят к блокировке Apple ID.

### Pairing-файл перестал работать

Он «протухает» после обновления или сброса iPhone, а иногда и сам по себе из-за изменений
на стороне Apple. Лечится пересозданием через iloader (кабель + ПК).

### `.ipa` не скачивается с GitHub на iPhone

Убедитесь, что репозиторий **публичный** или что вы авторизованы в GitHub в Safari.
Артефакты Actions требуют авторизации, поэтому используйте ссылку из **Releases**.
